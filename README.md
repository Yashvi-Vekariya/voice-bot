# 🎙️ Yashvi Voice Bot — AI Interview Assistant  
A fully interactive **Voice-Based AI Interview Bot** built using **HTML/CSS/JS + Node.js + Groq LLaMA-3.1-8B-Instant**, designed as an at-home assessment for the **100x AI Agent Team** interview.

This bot listens to your voice, converts it into text, sends it to an AI backend, receives the response, and speaks it back in your own voice style.

---

## 🚀 Features

### 🎤 **Voice Input**
- Start/Stop real-time voice recording  
- Chrome SpeechRecognition  
- Auto transcript display  
- Clean transcript UI  

### 🤖 **AI Response**
- Uses **LLaMA-3.1-8B-Instant** (Groq API)  
- Persona-based response (Yashvi — AI Engineer)  
- Interview Mode / Casual Mode  
- Smart suggestions  
- Typing animation  

### 🔊 **Speech Output (TTS)**
- AI-generated answer spoken aloud  
- **Stop Voice** button  
- Smooth transition and playback controls  

### 🎛️ **Modern UI**
- Dark/Light theme toggle  
- Visual audio bars  
- Glass morphism + gradients  
- Fully responsive  
- Animated interactions  

### 📁 **Utility Tools**
- Copy Q&A  
- Download JSON 
- Clear conversation  
- Local conversation history
